# ArtSpace

An independent, local-first vector illustration editor for desktop and browser, built with Uno Platform and SkiaSharp.

Implementation in progress. ArtSpace uses original icons and artwork and does not include Adobe code, branding, or proprietary assets. Adobe Illustrator is the interaction/design reference, not a claim of affiliation or complete compatibility.

## Provenance

The shared vector engine is derived from [VectorSpace](https://github.com/wieslawsoltes/VectorSpace), copyright 2026 Wiesław Šoltés, under the MIT license. ArtSpace-specific illustration tools and workspace are developed in this repository.
